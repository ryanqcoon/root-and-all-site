# Root + All website

Production-ready static site for **rootandall.com**, designed for GitHub Pages.

## Files

- `index.html` — complete one-page website
- `assets/root-and-all-logo.svg` — production logo
- `assets/favicon.svg` — browser favicon
- `assets/root-and-all-og.png` — 1200×630 Open Graph/social sharing image
- `CNAME` — custom-domain configuration for `rootandall.com`

## Publish with GitHub Pages

1. Create or open the GitHub repository that will host the site.
2. Upload these files to the repository root, preserving the `assets/` folder.
3. Commit/push to the `main` branch.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`, then save.
7. In Pages settings, confirm the custom domain is `rootandall.com`.
8. Configure DNS for GitHub Pages at the domain's DNS provider.
9. Once GitHub provisions the certificate, enable **Enforce HTTPS**.

## Updating the site

Edit `index.html` or replace files in `assets/`, then commit and push. GitHub Pages will redeploy automatically.
